# Michelle De Santa 3D — The Syndicate of Loyalty 🎩✨

> *"Reliable Friend • Calm & Serious • Loyal Companion"*  
> *Oral Presentation • English Topic*

![Michelle De Santa Presentation](assets/michelle_slide.jpg)

Стильный 3D приключенческий нуар-экшен, вдохновлённый оригинальной презентацией о лучшем друге **Michelle De Santa**.

Создано под **macOS** (нативное приложение `.app`), **Android** (готовый `APK` через GitHub Actions) и **Web** (GitHub Pages).

---

## 🌟 Особенности игры

- 🎩 **Каноничный 3D персонаж**:
  - Серая шляпа-федора с чёрной лентой.
  - Тёмный полосатый мафиозный костюм, галстук с серебряным зажимом, запонки.
  - Фирменный массивный золотой перстень на руке и серёжка в левом ухе.
  - Аккуратная борода и уверенный взгляд.
  - Процедурные анимации: мафиозная походка, бег, прыжки, удары, разбрасывание пачек долларов, и фирменная стойка «Спокойный фокус».

- 🏎️ **Винтажный гангстерский родстер V8**:
  - Детализированная 3D модель ретро-автомобиля 1930-х годов с хромированной решёткой радиатора и запасным колесом.
  - Физика вождения с заносом (дрифтом) и креном кузова.
  - Рабочие круглые фары (настоящие конусы света).
  - Ретро-гудок «Ahooga!».
  - Выхлопной дым и процедурный рык мотора V8.

- 🏙️ **Атмосферный 3D район (Santa District)**:
  - Мокрый асфальт с отражениями и лужами.
  - Дворцы и неоновые вывески: **De Santa Lounge & Jazz Club**, **Santa Trust Bank**, **Grand Auditorium**, пиццерия и ателье.
  - Центральная площадь с мраморным фонтаном, брызгами воды, скамейками и деревьями.
  - Живые прохожие и персонажи из лора.

- 📜 **Сюжетные миссии строго по качествам из презентации**:
  1. **«Надёжный друг» (The Reliable Friend)**: Выручи Томми из переулка, где его зажали ростовщики.
  2. **«Вовсе не жадный» (Not Greedy At All)**: Собери брошенные мешки с деньгами и раздай их друзьям района.
  3. **«Спокойный и серьёзный» (Calm & Serious)**: Останови вооружённый кризис в Santa Trust Bank без единого выстрела при помощи абсолютного хладнокровия и замедления времени (Bullet-time).
  4. **«Никогда не скучно» (Never Boring: The Oral Presentation)**: Доедь до Гранд Аудиториума и произнеси легендарную устную презентацию под салют над городом!
  5. **Песочница (Free Roam)**: Свободная езда по городу, дрифт, фоторежим.

- 🎷 **100% процедурный нуар-джаз саундтрек**:
  - Написан полностью на Web Audio API (звучит оффлайн, без сторонних mp3 файлов): контрабас, свинговые щётки, аккорды Rhodes piano, приглушённая труба, звуки шагов, ретро-клаксон и гул мотора.

## 🎮 Управление

### 💻 macOS / Клавиатура и Мышь:
| Клавиша | Действие |
|---|---|
| **W, A, S, D** / Стрелки | Движение персонажа / Управление авто |
| **Shift** | Бег (Спринт) |
| **Space** | Прыжок / Ручной тормоз в авто |
| **E** | Сесть в машину / Выйти из машины |
| **F** | Удар кулаком / Клаксон в авто |
| **Q** | Разбросать деньги («Вовсе не жадный!») |
| **C** | Спокойный фокус (Замедление времени Bullet-Time) |
| **H** | Сигнал авто («Ahooga!») |
| **L** | Вкл/выкл фары родстера |
| **M** | Вкл/выкл джазовую музыку и звуки |
| **Мышь (зажать и тянуть)** | Вращение камеры |
| **Колёсико мыши** | Приближение / удаление камеры |

### 📱 Android / Сенсорный экран:
- **Левый аналоговый джойстик**: плавное перемещение персонажа и руление автомобилем.
- **Кнопка [Drive]**: сесть в родстер V8 или выйти.
- **Кнопка [Punch]**: нанести удар / посигналить в машине.
- **Кнопка [Jump]**: прыжок пешком / ручник в машине.
- **Кнопка [Cash]**: разбросать пачки долларов.
- **Кнопка [Calm]**: активировать «Спокойный фокус».

## 🚀 Запуск и Сборка

### 1. На macOS:
- В репозитории уже собран готовый бандл **`MichelleDeSanta.app`**!
- Чтобы запустить локально прямо сейчас:
  ```bash
  open MichelleDeSanta.app
  ```
- Или откройте `index.html` в Safari / Chrome.

### 2. На Android:
- GitHub Actions автоматически собирает релизный APK при каждом пуше в `main`.
- Перейдите в раздел **Releases** или **Actions** на GitHub и скачайте готовый `MichelleDeSanta.apk`.
